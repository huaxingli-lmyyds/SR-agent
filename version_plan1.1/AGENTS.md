# 执行规则
- 本目录是 version_plan1.1 的唯一交付根目录；project/ 为隔离源码副本，原项目不覆盖。
- 严格按 TASKS.md 的 T1→T2→T3→T4 顺序；验证通过后才能完成任务。
- 恢复时先读 TASKS.md、PROGRESS.md，并核对源码清单与测试产物，从首个未完成项继续。
- 保留已有有效规则和用户修改；禁止复制密钥、数据集、虚拟环境、历史实验产物。
- 每阶段更新输入、输出、依赖、验收和实际证据；失败先修复，禁止将未执行实验写成结果。
- 默认自动处理可逆细节；只有关键输入、用户取舍或必要授权缺失时集中询问。
- 所有测试输出/缓存/实验产物写入本目录；使用现有隔离 Python 环境，不改全局 CUDA。
- 新行为可选且有界；模型只提建议，确定性策略校验后执行；最终测试集不得用于选择。
- 不自动启动昂贵训练或下载受限数据；本轮交付实验方案、配置和可运行预览。
